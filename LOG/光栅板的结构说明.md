## 1. 硬件机械结构概述

光栅板采用**双栅格条 + 双正交编码器**设计，实现按压与吹气的物理分离检测。

- **PCB 板**：竖直固定在连接**底板**与**按压板**的中心柱子上。
- **栅格条**（共两根）：
  - 下方栅格条：固定在底板上（静止不动）。
  - 上方栅格条：固定在**按压板**上，随按压板同步上下移动。
- **光电传感器**：共 4 个 ST130B，分两组安装在 PCB 两端，每组内部**错开一个相位**（实现 4 倍频正交解码）：
  - **Port D (OUT3/OUT4)**：位于 PCB 下端，**主负责按压检测**。
  - **Port C (OUT1/OUT2)**：位于 PCB 上端，**主负责吹气检测**。

## 2. 动作区分原理

### 2.1 核心运动逻辑

| 操作       | 按压板运动                 | 上方栅格条运动     | 主要触发传感器组       | 运动方向           | 代码对应变量                          |
|------------|----------------------------|--------------------|------------------------|--------------------|---------------------------------------|
| **向下按压** | 向下移动                   | 向下移动           | **Port D (OUT3/OUT4)** | 下压（正向）       | `depth_count_press` / `direction_press` |
| **吹气**     | 胸腔鼓起 → 按压板被顶起    | **向上移动**       | **Port C (OUT1/OUT2)** | 充气/向上（正向）  | `depth_count_blow` / `direction_blow`   |

**关键说明**：
- 虽然同一个柱子联动会导致按压时两组传感器都可能产生信号，但**硬件通过上下位置分离 + 专用传感器组**实现了**主通道区分**。
- **Port D** 是按压的主检测通道。
- **Port C** 是吹气的主检测通道。

### 2.2 方向定义（必须遵循文档规范）

- **按压方向**（Port D）：
  - `1` = 下压（按压进行中）
  - `-1` = 回弹（释放后向上回弹）
  - `0` = 静止
- **吹气方向**（Port C）：
  - `1` = 充气（栅格条向上移动）
  - `-1` = 泄气（栅格条向下移动）
  - `0` = 静止

## 3. 当前代码存在的问题

> ⚠️ 以下问题已在 v2.0 架构重构中全部解决。

1. **~~端口映射完全错误~~** ✅ 已修复
   - 代码中：`EXTI_PORTC_IRQHandler` → 按压、`EXTI_PORTD_IRQHandler` → 吹气
   - 硬件实际：`Port D` → 按压、`Port C` → 吹气

2. **~~方向值不符合文档要求~~** ✅ 已修复
   - 文档（业务需求.md §3.2）：`DIR: -1（回弹） / 0（静止） / 1（下压）`
   - 代码当前使用 `0 / 1 / 2`

3. **~~实时数据上报不完整~~** ✅ 已修复
   - 仅上报按压深度和方向，吹气实时数据（`depth_count_blow`、`direction_blow`）完全未发送给 Sensor 板。
   - 帧格式缺少类型标记，接收端无法区分按压与吹气数据。

4. **~~Flash 空间不足~~** ✅ 已解决（v2.0 架构重构）
   - STM8S003F3 仅 8KB Flash，成绩计算逻辑占用过多空间
   - 解决方案：STM8 降级为纯数据采集器，所有计算移至 Sensor 板

## 5. 预期工作流程（v2.0 纯采集模式）

1. Sensor 板发送**开始指令** → 光栅板清零计数器，进入 `RASTER_ACTIVE` 状态。
2. 每 100ms：
   - Port D 中断实时累加按压脉冲计数（`depth_count_press`）。
   - Port C 中断实时累加吹气脉冲计数（`depth_count_blow`）。
   - 计算自上次发送以来的脉冲增量（`delta = current - previous`）。
   - 通过 UART1 发送 8 字节原始脉冲帧给 Sensor 板：
     - 帧格式：`0xAA + 0x04 + TYPE + CNT_H + CNT_L + DIR + CHK + 0x55`
     - `TYPE`：`0x01`=按压数据，`0x02`=吹气数据
     - `CNT`：int16_t 脉冲增量
     - `DIR`：`-1`=回弹/泄气，`0`=静止，`1`=下压/充气
     - 按压和吹气不同时进行，`direction_blow != 0` 时发吹气帧，否则发按压帧
3. Sensor 板接收脉冲增量，累加并计算深度，执行全部成绩计算逻辑。
4. 操作结束 → Sensor 板发送**停止指令** → 光栅板直接返回待机状态。
